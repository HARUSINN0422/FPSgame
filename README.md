# Mobile FPS Web

Node.js + Express + Socket.IO + Three.js のブラウザFPSプロトタイプです。

## 特徴

- ポート **3007** で起動
- 武器を選択すると試合開始画面を挟まず、そのまま対戦マップへ参加
- サーバーへ接続しているプレイヤー同士が常時同じマップで対戦
- スマホ・タブレット向けのタッチUI
  - 左側: 移動ボタン
  - 右側: FIREボタン
  - それ以外の画面: スライドして視点操作
- PCでは WASD / 矢印キー / Space でも操作可能
- ハンドガン、アサルトライフル、ショットガンを選択可能
- 撃破時に自動リスポーン

## プレイヤースキン作成

- 武器選択画面の「スキンをペイントで作成」から、64×64ピクセルのスキン編集画面を開けます。
- ペン、消しゴム、塗りつぶし、色選択、ブラシサイズ、元に戻す、全消去、初期スキンへのリセットに対応しています。
- スキンはブラウザの localStorage に保存されます。同じ端末・ブラウザでは次回も利用できます。
- 保存したスキンは参加時にサーバーへ送られ、他のプレイヤーのキャラクターにも反映されます。試合中に設定画面から編集して適用することもできます。
- 標準的な 64×64 PNG スキンアトラスを使用します。キャンバス上で透明な部分は、上着や帽子などの外側レイヤーとして利用できます。

## 起動

Node.js 20以上を推奨します。

```bash
npm install
npm start
```

ブラウザ:

```
http://<サーバーIP>:3007/
```

同じURLへスマホ・タブレットからアクセスすると、同じゲームサーバーに接続できます。

## ゲームモード

### 乱闘（Melee）
- 全員が敵の通常対戦です。
- `map/Melee/` の `rotationOrder` 順に10分ごとにマップが切り替わります。切替5秒前からカウントダウンを表示し、切替時はMelee参加者を新マップへ移動します。

### エリア（Area）
- 3対3で、専用マップ中央の制圧エリアを奪い合います。
- どちらか一方のチームだけがエリア内に5秒間いると所有権を獲得します。所有チームのカウントは、エリアが無人でも、相手が奪取中でも継続し、相手チームが単独で5秒間エリアを確保すると所有権が切り替わります。進行速度は1.5秒ごとに1%、100%に到達すると勝利です。
- エリアを選ぶと20秒間マッチメイキングを行います。6人集まると即開始し、集まらなければBOTで人数を補って3対3にします。
- 試合終了後は勝敗と個人のK/Dを表示します。結果画面を閉じるとモード選択へ戻ります。
- BOTは通常の射撃・エイムに加え、制圧エリアへ向かい、制圧中はその場所を守る行動を取ります。

## マップの追加

- 乱闘のマップは `map/Melee/`、エリアのマップは `map/Area/` にJSONで保存します。
- それぞれのゲームモードは専用のマップ設定を使うため、マップ、当たり判定、プレイヤー表示はモード間で混ざりません。
- `map/Area/ControlCenter.json` がエリアモードの専用マップです。各フィールドの仕様は `map/README.md` と `map/Area/README.md` を参照してください。

## 注意

これは拡張用のプロトタイプです。次の段階では、マップの増設、武器モデル、弾数・リロード、銃声、より厳密なサーバー側当たり判定、認証、ランキングなどを追加できます。

## GitHub自動更新

`server.js` は起動後、60秒ごとにGitHubの `main` ブランチを確認します。

- GitHubに変更がなければ、そのまま動作
- GitHubに新しいコミットがあれば自動で `git pull`
- `npm install --omit=dev` を実行
- 新しいNode.jsプロセスを起動して、古いプロセスを終了

**重要:** 自動更新は `server.js` 自身の場所（`__dirname`）を基準にGitを操作するため、リポジトリをどのディレクトリに置いても動作します。現在のラズパイでは `/home/harusinn/Desktop/FPSgame` に配置しています。

そのため、ラズパイでは最初にリポジトリをcloneして依存関係をインストールした後、通常どおり `node server.js` を起動するだけで、自動更新が有効になります。

### Raspberry Piでの初回設定

現在の配置場所でのコマンド:

```bash
cd /home/harusinn/Desktop
git clone https://github.com/yumakasugai0422-cmyk/FPSgame.git
cd FPSgame
npm install
node server.js
```

以降はGitHubの `main` が更新されると、最大60秒程度でラズパイ側にも反映されます。

※ ラズパイ側で手動編集したファイルがある場合、`git pull --ff-only` が失敗して自動更新されません。基本的にこのリポジトリはGitHub側を正として使用してください。
